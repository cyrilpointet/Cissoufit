# Cissoufit

PWA de suivi d'exercices de fitness — React, TanStack Router, Tailwind v4, données en localStorage, déployée sur GitHub Pages.

## Documentation

La documentation de référence (besoins métier + fonctionnement technique) est [doc/documentation.md](doc/documentation.md). La lire avant toute évolution.

**Elle doit être mise à jour au fur et à mesure, dans la même modification que le code** :
- nouvelle fonctionnalité / règle métier → §2 (Besoins métier)
- nouvelle entité ou nouveau store localStorage → §2.3 et registre des stores (§3.4)
- changement d'architecture, de dépendance ou de config → §3
- choix structurant → une ligne dans le journal des décisions (§5)
